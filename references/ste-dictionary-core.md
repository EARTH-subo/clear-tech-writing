# STE 词典原则与高频对照

> Part 2 约 900 个批准词 + 约 1200 个不批准词（附替换建议），一词一义一词性。完整词典以官方 Issue 9 为准
> （免费索取：https://asd-ste100.org/STE_downloads.html）。
> 本文件只收高频对照，供改写时快速取用；条目为公开资料整理，个别取舍以官方词典为准。

## 词典原则

1. 一词一义：批准词只用于词典给定的含义（1.3）。
2. 一词一词性：词典标名词就只当名词用（1.2）。
3. 同义词只留一个：begin / commence / initiate / originate → 一律 **start**（1.11、9.4）。
4. 拼写以 Merriam-Webster 美式为准（1.14）。
5. 词典外词的合法通道只有两条：**Technical Names**（1.5）与 **Technical Verbs**（1.12）。词难不等于技术名词。

## 已知词性裁定（改写时最容易踩的）

| 词 | 裁定 | 结果 |
|---|---|---|
| test / check / work | 只作名词 | "test the pump" → "do a test on the pump"；"check that X" → "make sure that X" |
| oil | 只作技术名词 | 动词用 lubricate："Lubricate the linkage with oil." |
| help | 只作动词 | 名词用 aid："with the aid of" |
| fall | 动词只表物理下落 | 数值下降用 decrease |

## 句式与结构替换

| 不合 STE | 合 STE | 依据 |
|---|---|---|
| The valve should be closed. | Close the valve. | 3.6、5.3、情态阶梯 |
| Turn on the pump. | Start the pump. | 9.3 禁短语动词 |
| Carry out an inspection of the valve. | Examine the valve. | 3.7 禁名词化 |
| The system has been updated. | The system is updated. | 3.4 禁完成时 |
| The engine which is running at idle... | The engine at idle... | 3.5 -ing 限制 |
| Remove bolt and install new one. | Remove the bolt. Then install the new one. | Section 4 不省成分 |
| Check the pressure; then open the valve. | Make sure that the pressure is correct. Then open the valve. | 8.1 禁分号 |
| It is recommended that... | 直接给指令或事实 | 简洁原则 |
| In order to remove the bolt, turn the nut. | To remove the bolt, turn the nut. | in order to → to |

## 拿不准时的操作

1. 优先换成"最常用、最短、最具体"的近义词。
2. 是产品 / 部件 / 行业专名 → 按技术名词保留，全篇一致（1.5–1.11）。
3. 是专门动作 → 查技术动词类别（1.12），或改写为"动词 + 名词"结构。
4. 像 inspect 这类维修高频词，若属行业标准术语就按技术动词保留；只表示"查看"时用 examine。
5. 改写后句子若超长 → 先删冗余词，再拆句。
